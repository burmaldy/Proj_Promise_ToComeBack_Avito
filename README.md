# Авито.Миры

**Для решения кейс-чемпионата Changellenge.**

Интерактивный прототип: каталог и избранное, комнаты с товарами, гараж, сообщества и настройка интерьера.

## Последняя версия

**[Скачать готовый HTML в ZIP](https://github.com/burmaldy/Proj_Promise_ToComeBack_Avito/raw/refs/heads/feat/avito-worlds-latest/downloads/Avito_Miry_v9_visual.zip)**

[Открыть файл в репозитории](https://github.com/burmaldy/Proj_Promise_ToComeBack_Avito/blob/feat/avito-worlds-latest/Avito_Miry_v9_visual.html) · [Все файлы последней версии](https://github.com/burmaldy/Proj_Promise_ToComeBack_Avito/tree/feat/avito-worlds-latest)

Распакуйте ZIP и откройте `Avito_Miry_v9_visual.html` в браузере. Изображения, стили и JavaScript встроены; установка и сборка не нужны. GitHub показывает код HTML, а запускать прототип нужно в браузере после скачивания.

В последней версии материал пола меняется в самом изображении комнаты. Пользователь может редактировать границы размещения; предметы размещаются внутри контура без пересечений. Для собственного загруженного фото материал пола задаётся самим фото.

Версия подготовлена в отдельной ветке. После слияния Pull Request HTML появится в списке файлов основной ветки.
